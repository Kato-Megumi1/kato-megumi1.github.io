# PengYao's personal website

English personal website for an incoming graduate student at Tianjin University, interested in embodied intelligence and reinforcement learning.

Live site: https://kato-megumi1.github.io/

## Editing

- `index.html`: biography, interests, project description, and links.
- `style.css`: responsive layout and visual design.
- `site.js`: video play button.
- `assets/chatforum-demo.mp4`: product walkthrough.
- `assets/demo-captions.vtt`: English captions.

This is a static site with no build step, analytics, cookies, or third-party JavaScript. GitHub Pages serves the root of `main`; `.nojekyll` keeps the files unchanged.

The ChatForum walkthrough is the screen recording supplied and approved by the project owner. It is encoded for web playback with its original content and timing retained, and includes optional English description captions. It illustrates the product and is not a model-quality benchmark.

Project source: https://github.com/Kato-Megumi1/chatforum

## Design references

Researched [al-folio](https://github.com/alshedivat/al-folio), [Academic Pages](https://github.com/academicpages/academicpages.github.io), and [Minimal Light](https://github.com/yaoyao-liu/minimal-light). This site is a custom static implementation inspired by their concise academic structure; it does not include their code or sample publications.
